# Zynnos Labs — Sitio Web

Landing page oficial de Zynnos Labs.

## Stack
- HTML single-file (sin frameworks ni build tools)
- GSAP 3.12.5 + ScrollTrigger
- Lenis 1.1.14 (smooth scroll)
- Deploy automático via Vercel

## Estructura
```
zynnos-site/
├── index.html     ← todo el sitio
├── vercel.json    ← configuración de deploy
└── .gitignore
```

## Deploy

Cada `git push` a `main` actualiza el sitio automáticamente en Vercel.
